Web Accessibility

What Does Accessibility Mean?

Accessibility means that a website can be used by as many people as possible, regardless of physical, sensory, or cognitive limitations. This includes people with visual, hearing, motor, or cognitive impairments, but also people who, for example, can only use a keyboard instead of a mouse.

Key Aspects of Accessibility

  1. Alt Text for Images
    Every image should have an alt attribute with a meaningful description, so screen readers can convey the content to blind or visually impaired users.

  2. Sufficient Color Contrast
    Text must stand out clearly from the background so that people with low vision or color blindness can read the content. WCAG guidelines recommend a contrast ratio of at least 4.5:1 for normal text.

  3. Keyboard Operability
    All interactive elements (links, buttons, forms) must be reachable and operable without a mouse, using only the Tab key.

  4. Semantic HTML
    Using the correct HTML elements (<nav>, <header>, <button> instead of a <div> with a click handler, etc.) helps assistive technologies correctly interpret the page's structure.

  5. Labeled Forms
    Every input field should be linked to a <label>, so screen reader users know what to enter.

  6. Understandable Language and Structure
    A clear structure with logically nested headings (<h1> to <h6>) helps not only screen readers but also people with cognitive impairments to navigate the page.

  7. No Color-Only Coding
    Important information (e.g. error messages) must not be conveyed through color alone; it also needs text or icons - important for color-blind users.

  8. Scalable Font Sizes
    Text should be specified in relative units (e.g. rem) so users can increase the font size in their browser without breaking the layout.

Personal Conclusion

Accessibility used to be a fairly abstract topic for me, one I associated with "extra effort for a small group of users." Working through it, though, made me realize that many measures - such as semantic HTML, good contrast, or keyboard operability - actually improve usability for everyone, not just people with disabilities. Going forward, I plan to think about alt attributes and labels from the start, rather than adding them as an afterthought.
